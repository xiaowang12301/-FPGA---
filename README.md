## 初步的颜色实现
我先完成了从摄像头的识别到vga的显示,也就是不做任何算法,仅把显示逻辑的打通.后面加入了对rgb转YCbCr,为什么我要这么做呢,因为我要识别不同的颜色,然后发现如果只是使用rgb作为条件判别怎么都不成,上午还能判别到,下午就判别不到了,后来发现rgb受亮度影响很大,因此这个时候在网上看视频发现原来还有这种可以把亮度分离的格式,然后就用了这种格式,识别效果非常的可以,我的判定逻辑是如果当前坐标点的数据满足这四个颜色的判别,就把给vga的数据分别是他的数据,然后显示就非常的nice,在视觉上看到的就是其他都是黑色,物块摆上去就是他的颜色.后面加了腐蚀和膨胀算法,加了x坐标和y坐标的计数,基本上打通了识别的框架.
## 西电哥们的神助
可是这个时候也没办法对单个物块完成处理,可以发现现在我只完成了物块颜色的识别,当时被困在这上面有点久,后面在b站上看了网上西电哥们的视频,使用了他的思路,摄像头在扫描和vga的扫描逻辑是想通的,都是从上到下从左往右,那么他必定会先扫描到一个物块,我可以通过第一个有效点的范围来判别其他的有效点也是这个物块.通过实际探究我完成了这个范围应该为多少.这个范围也决定了粘连的大小.现在,我可以实现单个物块的识别了.物块的类型识别就是这个范围内有效点的多少,四个形状的有效点是不同的,那么接下来,就是数学魅力时刻,角度的判别.
## 角度--数学魅力时刻
要计算角度,我的思路是需要先转到一个固定的角度,对于一个正方形，圆形来说只需要转正就好了,对于三角形来说就是我要把它旋转成两条直角边连接的端点一直是整个物块的右下角,这就是计算的角度.对于六边形,是可以看出他是有两种形式的,一种是角朝上,一种是边朝上,但是我这里实在没想到怎么计算角度.因此这里只能把它转正后赌这二分之一的运气了.这就是我的初步思路,在实现过程中首先完成了正方形的角度,这里使用了CORDIC算法,我把角度通过串口输出确实很准,因此后面三种也是这个算法.后面发现颜色角点只能处理正方形,如果要处理其他形状,就需要这个透明正方形的角点,也就是说要有边缘角点,因此使用了Sober核处理y分量,如果有效值为1输出给vga就是黄色,然后通过这个完成边缘角点的识别,完成边缘角点的时候后就很好做了,完成最上面和最下面边缘角点的获取,这个时候通过计算他们的y变化量和x变化量,通过CORDIC计算出角度,这个角度-45°就是需要转正的角度.三角形需要用颜色角点判别那个两条直角边连接的端点在左侧还是在右侧,判别到后在刚刚计算后的角点上加减值即可得到需要转成端点在右下角的角度.
